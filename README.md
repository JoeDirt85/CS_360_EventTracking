## Briefly summarize the requirements and goals of the app you developed. What user needs was this app designed to address?
This apps goal was to allow users the ability to add, update and delete events from a database, that stored their user and event information. It would 
then use this information to display the events onto a screen, giving the user an easy follow UI to interact with. It was designed with the idea that 
users would like the ability to add and track important events in their lives, from a single dashboard. 

## What screens and features were necessary to support user needs and produce a user-centered UI for the app? How did your UI designs keep users in mind? Why were your designs successful?
I designed three screens for this application. One was a login/account creation screen, that prompted the user to login to an account. It also had the main display, that showed a grid view of all 
events associated with their account. As well as an event detail screen that showed the details of a single event and allowed the user input event information or opt into SMS notifications. I feel that my 
design kept users in mind, because I tried to keep the interaction on each screen to have only the essentials as to not overload the users with options. I think this was successful because 
it keeps the app straight forward and performs the intended task. 

## How did you approach the process of coding your app? What techniques or strategies did you use? How could those techniques or strategies be applied in the future?
For the programs development, I started by designing the UI and the components in which users would interact with. This gave me a sense of what I could expect from the app
and what I needed to code to implement them. From there, I attempted to program one screen at a time, but quickly found that to be an ineffective method. So, I shifted to jumping around 
and getting everything related to certain actions done. For example, in order to login and save the users information, I needed to write the code to create the database and its tables, then had to create 
the method for adding users. This allowed me to make real progress and have testable code, so that I could verify my work. I think this could be applied to future projects because it allows me to not think 
linearly and think of the project as a layered system that needs to interact to function properly.  

## How did you test to ensure your code was functional? Why is this process important, and what did it reveal?
To test this project, I used a device emulator that ran the app and allowed me to manually test the features. This method not only allowed me to test the code itself, but 
also allowed me to test how it would be from a users perspective. The testing process is very important, as it tends to reveal flaws within a program. In my testing, it often revealed 
that certain interactions would crash the application, as well as some minor UI flaws, that I would end up changing to create a better display. 

## Consider the full app design and development process from initial planning to finalization. Where did you have to innovate to overcome a challenge?
During the entire development process, the biggest challenge I faced was implementing the interaction between the UI and the database. I was able to overcome this challenge 
by doing thorough research tow rite effective Java code that handle the interaction. I also performed manual testing to ensure that this interaction was correctly implemented.

## In what specific component of your mobile app were you particularly successful in demonstrating your knowledge, skills, and experience?
Normally, my weakness is in the UI design, but I feel that in this project, I was able to overcome this and develop a UI that met the goals for the application. The design method used in this 
for this application was very new to me, however, I was able to quickly learn how to work with the XML files and develop the layout and various interactive components.
